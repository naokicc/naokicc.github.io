# Personal Website

A minimal personal website with placeholder content for About, Research, Publications, and Notes.

## Edit the website

1. Open `index.html` in this repository.
2. Select the pencil icon to edit the file.
3. Replace the text inside the relevant section. Keep the HTML tags in place.
4. Select **Commit changes** and commit to `main`.
5. GitHub Pages publishes the updated page automatically after deployment completes.

The page title and description are near the top of `index.html`. Colors, spacing, and typography are in its `<style>` block. No build tools or external services are required.

## Publishing

In **Settings → Pages**, select **Deploy from a branch**, branch **main**, and folder **/ (root)**.

All text is placeholder content. Add only information you want to publish publicly.
